# AO3 Reader GitHub Pages

Landing page for [AO3 Reader](https://ao3-reader.github.io/), an unofficial Archive of Our Own reader for iPhone and Android.

## Deploy

1. Upload all files in this repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Save.

The site will publish at:

`https://ao3-reader.github.io/`
